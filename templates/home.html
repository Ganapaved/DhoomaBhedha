🐝 Smart Beehive Gas and Weight Monitor

Real-time monitoring of gas levels and hive weight to ensure beehive health and honey production.

About this Project

This project uses ESP32, gas sensors, and a load cell with HX711 to monitor gas levels (e.g., CO2 or dangerous gases) and hive weight. Real-time data is pushed to this dashboard using a Flask server backend with SQLite storage.
